RetailPulse Capstone – Retail Analytics
CORE COMMANDS USED
============================================================

This file contains the main project/workflow commands only.
Troubleshooting, failed commands, error-fixing commands, diagnostic-only
commands, service-restart commands, and temporary problem-solving commands
are intentionally excluded.

Project flow:
RDS PostgreSQL → Sqoop → HDFS/Hive Bronze
Streaming JSON → Flume → Kafka → Spark → Hive Silver/Gold
Hive Gold → Presto → Metabase

============================================================
4. HDFS – BRONZE DATA
============================================================

Create Bronze root:

hdfs dfs -mkdir -p /data/retailpulse/bronze/postgres

List Bronze tables:

hdfs dfs -ls /data/retailpulse/bronze/postgres

List a specific imported table:

hdfs dfs -ls /data/retailpulse/bronze/postgres/<TABLE_NAME>

Read imported files:

hdfs dfs -cat /data/retailpulse/bronze/postgres/<TABLE_NAME>/part-*


============================================================
5. HIVE – BRONZE DATABASE
============================================================

CREATE DATABASE IF NOT EXISTS retailpulse_bronze;

USE retailpulse_bronze;


============================================================
6. HIVE – BRONZE EXTERNAL TABLES
============================================================

The Bronze Hive tables point to the Sqoop HDFS directories.

General structure:

CREATE EXTERNAL TABLE <table_name> (
    ...
)
ROW FORMAT DELIMITED
FIELDS TERMINATED BY ','
STORED AS TEXTFILE
LOCATION '/data/retailpulse/bronze/postgres/<table_name>';


Tables created for the source data:

stores
customers
products
orders
order_items
payments
fulfillment_events
inventory_snapshots


============================================================
7. FLUME – STREAMING INPUT
============================================================

Streaming source:

base/flume/lab_data/retailpulse/

Generated event files follow the pattern:

retailpulse_events_<timestamp>_<batch>.json


Flume configuration file:

base/flume/flume.conf


Flume configuration repository copy:

configs/flume.conf


Flume reads the newline-delimited JSON event files and sends them
to the Kafka topic used by the RetailPulse streaming pipeline.


============================================================
8. KAFKA – RETAILPULSE EVENTS
============================================================

Kafka topic:

retailpulse-events


Start a console consumer from the beginning of the topic:

kafka-console-consumer.sh \
  --bootstrap-server localhost:9092 \
  --topic retailpulse-events \
  --from-beginning


Streaming flow:

Flume → retailpulse-events → Spark


============================================================
9. SPARK – STREAMING / ETL
============================================================

Spark consumes the RetailPulse Kafka events and performs the
streaming transformation required before the Silver/Gold Hive layer.

Logical pipeline:

Kafka
  ↓
Spark
  ↓
Silver
  ↓
Gold


The Spark processing is represented by:

notebooks/retailpulse_pipeline.ipynb
